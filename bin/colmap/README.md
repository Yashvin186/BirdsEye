# COLMAP Binaries

Place your extracted COLMAP distribution here, or install COLMAP globally in your system `PATH`.

Recommended Windows setups:
- `bin/colmap/COLMAP-3.9.1-windows-cuda/COLMAP.bat` (for NVIDIA CUDA support)
- `bin/colmap/COLMAP-3.9.1-windows-no-cuda/COLMAP.bat` (CPU fallback)

Download official releases from:
https://github.com/colmap/colmap/releases
